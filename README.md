### Prerequisites
- **Target OS**: Windows 10 or Windows 11 (64-bit architecture)
- **Runtime Environment**: Python `3.10+` installed ([python.org](https://python.org))
- **Shell**: PowerShell (Run as Administrator recommended for Registry monitoring)

<br>

```powershell
# 1. Clone the ThreatLens repository
git clone https://github.com/stebyvarghese1/ThreatLens.git
cd ThreatLens

# 2. Spin up isolated Python environment
python -m venv .venv
.\.venv\Scripts\activate

# 3. Inject cyber security dependencies
pip install -r requirements.txt

# 4. Initialize the ThreatLens Command Center
python -m app.main
```
